# 검증 기준

## 기능 확인

- 로컬 mock과 FastAPI 모드에서 토리·나루 공간 카드, 배경, 프로필, 새 채팅을 확인한다.
- 기존 설치 데이터를 복원해도 앱이 시작되며, 이전 공간 기록 때문에 새 공간 선택이나 대화 목록이 깨지지 않는지 확인한다.
- 메시지 전송·오류 재시도, 채팅 재개, 배경 보기·뒤로가기, 음원 전환을 확인한다.
- 그림일기 생성·취소·재시도·저장·재시작 복원, 비공개 기본값과 로컬 공유 흐름을 확인한다.
- 이전 공간의 서버 대화는 목록에서 숨겨지고 새 답변 요청이 거부되며, 기존 DB 데이터가 그대로 남는지 확인한다.

## 코드 검증

`mobile/`에서 `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd test`를 실행한다. `backend/`에서는 `python -m pytest -q`와 `python -m alembic check`를 실행한다. Expo 번들 검증은 `mobile/README.md`의 명령을 따른다.

에뮬레이터·실기기를 확인하지 않았다면 화면 동작을 검증했다고 보고하지 않는다. 실제 실행 명령, 통과 여부, 미검증 환경을 `docs/PROGRESS.md`에 기록한다.
